# 🎬 Movie Showcase & Download Landing Page

A simple, responsive static website designed to showcase a curated movie collection, complete with direct streaming or download anchors. This project highlights semantic HTML structure and responsive CSS styling.

## 🚀 Live Demo
👉 [View Live Website]([https://castro212010.github.io](https://castro212010.github.io/mcu-timeline/))

## ✨ Features
- **Movie Spotlight:** Showcases a clean, prominent display of the movie title, poster, and overview.
- **Direct Access Action:** Includes a fully styled download anchor element (`<a>` tag) for instant file access.
- **Responsive Layout:** Works smoothly on desktop viewports and mobile devices.

## 🛠️ Technologies Used
- **HTML5:** For structural elements and semantic markup.
- **CSS3:** For customized layouts, flexbox alignments, custom colors, and button hover states.
- **JavaScript (Optional):** Used for any dynamic functionality (like search or click interactions).

## 📂 Project Structure
```text
├── index.html       # Main webpage structure
├── style.css        # Custom CSS styles and layouts

```

## 💻 How to Run This Project Locally

To view and edit this website on your local machine, follow these steps:

1. Clone or download this repository to your desktop.
2. Open the project folder in a text editor like VS Code.
3. Double-click the `index.html` file to launch it instantly in any web browser.
